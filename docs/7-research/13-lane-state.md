## 5. Instruments — all public, all re-derivable, all verified working

1. **Achievement funnel** — `steamcommunity.com/stats/<appid>/achievements/`, parsed by splitting on
   `class="achieveRow`, then `achievePercent">([\d.]+)%` and `<h3>`/`<h5>`. Denominator is
   achievement-tracked owners, never sessions.
2. **Rarity floor** — the rarest achievement in a title. 0.1–1.5% across the first eight, except
   Scritchy Scratchy at 12.1%. Separates engagement from completion space. Added `12`.
3. **Review corpus** — `appreviews`, `language=english`, `purchase_type=all`, `filter=recent`,
   cursor-paged to n=1,000. Gives full text + `playtime_at_review` + vote direction.
4. **Store facts** — `appdetails` (`coming_soon`, price, dev/pub, genres, full description).
