# C15 TextMeshPro migration — sequencing plan (orchestrator, 2026-08-05)

**Authority:** C15 (Allen, Option 1, 2026-08-02) — both surfaces migrate;
orchestrator schedules per surface; every signed type deviation expires when
its surface migrates. **Status: STAGED — kicks off after batch 10's verdicts.**

## Why this order

**Phase L — the laptop surface first** (SureThing + markets' elements; one
Unity canvas family, one migration):
- The surface is functionally complete and merged; only DD verdicts remain.
  Migrating now invalidates the fewest in-flight items.
- It carries the most signed type debt: tracking (S28), tnum (S29), weight 600
  (S20/S28) — all expire here. Markets' ladder letter-spacing deviation
  dissolves with it.
- Faces are settled (Archivo + Archivo Narrow, S11) and TMP assets were named
  in S11's own ruling ("one LoadFont + two TMP assets").

**Phase T — the TV surface second:**
- Touches the HDR emission material path (TvSweatHdrUI.shader) — the risky
  half; better attempted after Phase L teaches the studio the migration shape.
- Blocked until its gold-flash fix (T58) lands and gets its verdict, else we
  re-capture twice.

## Preconditions (hard, per phase)

1. Batch 10 lands: LEDGER grant (Phase L) / T58 verdict (Phase T).
2. C3's one-token invariant restated for TMP materials before the first commit.
3. Per-surface capture re-baseline BEFORE migrating (the before-set), full
   re-capture after — the DD re-verifies every Design-verified item on the
   migrated surface (C11: type changes every slot).
4. Leads' scope sections confirmed current in their handoffs at kickoff.

## Shape

- One surface at a time; never both mid-migration.
- Each phase: scope confirm → before-captures → migrate (lead, sub-agents
  encouraged) → suites green → after-captures → DD re-verification drag →
  deviations formally expired in the register.
- Editor lease: the migrating lead owns it for the phase's capture windows.
