One settled ticket in the Ledger (the runtime's Old Slips), read-only.

```jsx
<LedgerEntry number="R2 · TICKET 02" terminal="LOST" stake="$180" payout="$0"
  legs="Kestrels ML −300 · Under 2.5 +105" />
```

Filters and renders settled `Run.Tickets`; it never infers a payout or an outcome. A lost ticket is struck through in the house's oxide and dropped to `--toner-3` — the strike carries the state so the colour never has to. An empty ledger says so explicitly at the 13px floor.
