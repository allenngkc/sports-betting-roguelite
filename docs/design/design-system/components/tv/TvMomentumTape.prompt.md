```jsx
<TvMomentumTape samples={[-0.2, 0.1, 0.4, 0.6, 0.3, -0.1]} />
```

Ruled in 2026-07-31 (T16) because PRD §4.2 names it in the one-revealed-source-of-truth law. Three hard rules: **no numerals** (the moment it needs one it has become the banned win-probability readout), **no hue** (white and grey only — everything on this surface except gold is colourless), and **never above L2** (it must not compete with the score above it or the live `NEED` line beside it). Within that ceiling the label and the current sample sit at L2 — §3 puts labels there — while the sample history sits at L1 as structure.

It is movement, not an event, so it never goes in the event strip — that line is one authored explanation that punches once and settles.
