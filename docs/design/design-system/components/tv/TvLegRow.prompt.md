A leg row in the TV ticket column. The state is carried by brightness first, by the literal state word second.

```jsx
<TvLegRow market="TOTAL GOALS" price="-110" statement="Over 2.5 goals" state="LIVE"
  progress="LIVE • 2 GOALS • 1 MORE" />
```

`statement` is the headline in every state and is printed verbatim from VISUAL-DESIGN §6 — never paraphrased, never abbreviated. The progress line beneath carries what the leg still needs.

`LIVE` carries the surface's only pulse, off one shared clock so concurrent live legs breathe together. `L` goes to L0 and remains as unlit pixel structure — loss is darkness, not red. Ticket order is fixed: rows are pushed, never reordered.
