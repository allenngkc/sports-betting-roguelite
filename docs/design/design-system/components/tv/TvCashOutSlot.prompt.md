The cash-out slot: one fixed rectangle at the foot of the ticket column, owning all six states.

```jsx
<TvCashOutSlot state="actionable" amount="$184" keyHint="[E]" />
```

Actionable is the surface's only L4 element — a solid gold field with dark type punched out. `updating` stays at L3 because the offer is not yet acceptable. The rectangle never resizes; suspended and unavailable simply go nearly dark in the same space.
