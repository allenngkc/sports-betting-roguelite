# S85's treatment, proposed on a frame — the field carries the offer, the type carries the fact

**Ruling implemented:** `S85` §2 — *at the leg cap an unavailable price STOPS BEING AN OFFER AND
REMAINS A FACT.* **Proposed against §7's five constraints** · **Surface:** SureThing — the laptop.
**Before-state for comparison:** `dd-import/surething-board-leg-cap-2026-08-15/` — same seed, same
view, the state before any treatment.

**A read IS invited on the treatment.** §7 routed the proposal to this lane; the ruling is the DD's.

---

## The proposal, in one line

**The FIELD is removed; the TYPE is untouched.** A price that is still takeable sits in a field. A
price that is only true is bare type on the paper.

**It is not invented — it is S69's own move.** This surface already says *unavailable* by taking the
fill away and keeping the control's type: *"a disabled LOCK is TRANSPARENT, per LockAction.jsx — it
carried a fill and no border, which is the inversion of the kit."* A capped price is the same class:
legible, not currently takeable.

### Against §7's constraints, each one

| constraint | how |
|---|---|
| removes the offer affordance, keeps the price legible | the field goes; the label is untouched at `--toner`, same size, same tracking |
| distinguishable from `frozen` | **opposite channels.** `frozen` dims the TYPE and keeps the field; the cap keeps the TYPE and removes the field |
| no fourth ink | **it adds no ink at all** — the treatment is a subtraction |
| no code he must learn | *things in a box can be taken; bare type is information.* The board already teaches it — matchup names and season records are bare, prices are in cells |
| applies to every refused offer | applied at all four sites; **see the scope finding below, which is the part that needs a ruling** |

## What is in frame

Read against the 2026-08-15 before-frame, same seed, same board:

- **The four ringed cells keep their fields.** They are still offers — in the other direction.
  Un-picking is the remedy and a remedy is never disabled (S73-am4, disposition 3).
- **`DRAW`, `HOME` and `05 MALLARDS · AWAY +239` have lost theirs.** Fourteen cells, now bare type.
- **Every price is still fully legible at full strength.** Nothing is dimmed.
- **`MORE ›` keeps its field** — §6's clause: it opens a sheet, it does not take a pick.
- **The head reads `MY MARKS · 4 OF 4 SELECTIONS · 0 STAGED`.**

### The cause, stated once (§1)

`4 OF 4 SELECTIONS`. **No new vocabulary** — the head already states how many he holds, and the cap
is a fact about that count, so the denominator *is* the cause. It appears **only at the cap**, so it
never reads as decoration. Measured: it fits the count slot without the fitter truncating it, and
that is asserted rather than eyeballed.

## THE SCOPE FINDING — §6 asked for this, and the answer is not clean

**The treatment covers the board. It cannot cover the ENTRY sheet, and the reason is structural.**

`MarketOffer.jsx` gives the interior price cell **no fill**. Its cell is transparent today, live or
dead — so *there is no field to remove one screen deeper*, and the treatment that expresses the rule
on the board is a no-op there.

**Which surfaces something the frame could not show: the two surfaces do not share an offer
affordance at all.** On the board a live offer sits in a field. On the ENTRY sheet a live offer is
**already bare type**. So a dead ENTRY offer is indistinguishable from a live one — not because the
treatment failed to reach it, but because **a live one already looks like a fact**.

**What was done anyway:** the behavioural half is applied everywhere. At the cap, ENTRY's offers stop
accepting the click exactly as the board's do, so the act never happens on either surface.

**What is NOT done, and is a ruling rather than a lane's call:** giving ENTRY's price cells a field
so they have one to lose would contradict the kit. **This seat will not invent a second channel for
the interior list, and flags that §6's clause cannot be satisfied by this treatment alone.**

## NOT CLAIMED

- **No read is offered on whether bare type reads as "not available"** rather than as an ordinary
  fact line. That is the question this frame exists to answer.
- **The ENTRY sheet is not photographed.** Its cells are unchanged visually by design — there was
  nothing to change — so a frame of it would show the before-state and prove nothing.
- **The inversion is not re-argued.** S85 §5 accepted it; this build implements it.
- **No claim that the field is the only possible channel** — only that it is the one this surface has
  already ruled for exactly this meaning, and that it costs no new ink.
