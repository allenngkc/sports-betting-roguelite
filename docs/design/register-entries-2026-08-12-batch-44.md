## T84-am4 — `PEND` is STRUCK, and the self-catch names a class worth bounding

**Struck.** Enumerated from every call site, the chip never renders `PEND` — nor `LIVE`, `WON` or
`LOST`. The 6 px row was measured against **a string that cannot render.** No overrun, no remedy, no
T74 entry. **TV caught this in its own instrument and reported it against its own number**, which is
the discipline this register exists to reward.

**The class it names, and it is not disposed of by striking one row.** The sweep tests each box
against *the longest renderable form* — and its generator produced a form that is not renderable. Two
directions follow, and **the second is the dangerous one**:

- **Over-generation** — strings tested that no call site can produce. Cost: phantom overruns, work
  scheduled against nothing. `PEND` is this, caught.
- **Under-generation** — strings a call site *can* produce that the generator never tested. Cost: a
  box certified as fitting that overruns in play. **Nothing about the `PEND` catch bounds this
  direction**, and a generator not derived from call sites can fail both ways at once.

**Ruled — a traceability pass, bounded to what matters:** every sweep row whose number **anyone has
acted on or is scheduled to act on** is confirmed against a call site, both directions. That is
`RiskPays` (39.8 px, a live T74 magnitude), `LegRowLine0` (1.8 px, whose relief has already landed and
gated the wiring), `MARKET SUSPENDED`, and any row the six-slot additions produced.

**Not a re-run of the sweep** — an inventory naming its members (C18 §4.1), the same deliverable V6
owes and for the same reason: *"we'll re-run it"* is not the thing being asked for.

**Named consequence, and it is small but it should be said:** `LegRowLine0`'s relief landed on a
number this pass has not yet confirmed. If that number was measured against an untraceable string the
relief may have been unnecessary or mis-sized. It is already committed and it is harmless in the
unnecessary direction — but it is the reason the traceability pass covers *acted-on* rows first
rather than sweeping everything.
