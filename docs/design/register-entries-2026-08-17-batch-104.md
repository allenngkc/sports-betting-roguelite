## `C53` — the instrument change, worded for build

**The law:** *a classification with no category for the truth will file the truth under a falsehood.*
The sweep's §4.2 prints `UNACCOUNTED FOR — this number must be 0` and reports **12**. Those slots are
covered — but the only available category is *renders no string*, **false for all twelve.** The
invariant **lies rather than gaps**, and it lies because the taxonomy left nowhere true to put them.

**General form: an instrument may report that it did not measure something; it may not assert a REASON
it has not checked.** A category is a claim. **This is batch 98 one level up**, where thirteen TV rows
sat in the SureThing table because the structure put them where the heading said.

**Four clauses:**

1. **A third category — `DELEGATED`:** covered by a **named** other instrument.
2. **The name must resolve.** A delegation to a name that does not exist is a lie with extra steps, so
   the sweep **fails** when the named instrument is absent. Renaming or deleting a pin must break
   loudly — the defect being fixed is a silent false claim.
3. **`UNACCOUNTED FOR = 0` does not absorb it.** It stays a hard invariant on its own terms; delegated
   slots report on their **own** line with count, list and instrument named — a positive statement,
   never an absence. **A fix that quiets the alarm by widening what counts as accounted-for is the
   same defect with better manners.**
4. **THE TRAP, most likely to be missed: `DELEGATED` must distinguish COVERED from SCHEDULED.**
   *Covered* means the named instrument **has run and docked**. **`T101`'s residual was found in this
   same window to be "never run and never docked."** A category that cannot express that would report
   the panel COVERED while it was UNMEASURED — **recreating the identical lie one level up, inside the
   fix for it.** A delegation is a claim with its own staleness and carries its own evidence date.
