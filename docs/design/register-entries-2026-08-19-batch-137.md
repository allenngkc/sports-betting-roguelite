# Register entries — batch 137 (2026-08-19)

**THE THREE THAT BREAK THE GRAMMAR BREAK IT THE SAME WAY, AND ONE NEW STATE PAIR FIXES ALL THREE.**
`CorrectScore`, `TotalGoalsOddEven` and `WinningMargin` are the only kinds whose quantity is **not
monotone** — an exact score can be drifted off, a parity flips on every goal, and **a margin can
shrink.** The existing progress grammar assumes a count that only rises.

**Two rows.** **Destination table:** TV (`G1-am3`, `T151`).

**Authoring doc:** `docs/design/g1-point-markets-2026-08-19.md`.

## The rows

| G1-am3 | The MONOTONE test — three of `G1`'s nine break the grammar for one reason, read off the engine's own quantities | **RULED — DD 2026-08-19 batch 137, discharging three of the nine `T130-vf` found unauthored.** **THE EXISTING PROGRESS GRAMMAR IS A COUNT AGAINST A LIMIT (`0 GOALS • LIMIT 1`, `4 CORNERS • NEED 5`) OR A ONE-WAY FLAG (`SCORED`/`NOT YET`). BOTH ASSUME THE QUANTITY MOVES ONE WAY.** For `CorrectScore`, `TotalGoalsOddEven` and `WinningMargin` it does not: **an exact score can be drifted off, a parity flips on every goal, and a margin can SHRINK.** **THE CLASSIFICATION, AND IT IS THE ENGINE'S RATHER THAN A MATTER OF TASTE: a MONOTONE quantity takes a count-against-a-limit progress line; a NON-MONOTONE requirement takes a satisfied / not-satisfied pair.** That is why exactly these three broke it and nothing else did. **THE PLAYER-FACING POINT, which is the gap `T130-vf` photographed as a blank column: on these three the requirement can be CURRENTLY SATISFIED AND COMPLETELY UNSETTLED** — a correct-score backer at `3-1` in the 60th minute is exactly right and entirely unsafe — **and no existing progress form can say that.** **RULED: the pair is `MET` / `NOT YET`.** `NOT YET` is not new — it is AnytimeScorer's own word, meaning the same thing. **`MET` is the only new word in this pass: it reports that the requirement is satisfied NOW and says nothing about whether it will hold, which is exactly the fact and exactly its limit.** **`HOLDING` WAS AUTHORED FIRST AND WITHDRAWN, recorded so it is not re-proposed: it collides at the root with `HOLD E`, the cash-out status word (`T88`), which can be in the same frame — `T133`'s `PAID`/`PAY $60` shape, and this seat is not authoring into it two batches after ruling on it. `MET` also sits better with §8 — the theatre REPORTS — where `HOLDING` implies precariousness** | batch 137 · `g1-point-markets-2026-08-19.md` |
