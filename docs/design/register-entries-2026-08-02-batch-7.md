## Register integrity

- **C22 law · DD 2026-08-02:** the tables are the canon; a batch file is a draft until it is
  transcribed. A ruling exists when it is a row in REGISTER.md. Every batch ships as one
  `register-entries-<date>-batch-N.md`; the orchestrator transcribes it into the tables and reports
  the ID list back; this seat reads the tables, never its own batch files, before issuing a new
  batch. Nothing is "canonical alongside" the register. Three incidents in three days earned this
  and all three are one defect: a session issued T22–T27 over numbers batch 4 had spent; batch 5 was
  ruled, dispatched and obeyed but never entered the tables; batch 6 then re-ruled four room items
  because the tables it read did not contain them. This is C18 turned on my own instrument — a
  register that does not say what it is missing is a claim that does not say what it covers. The
  tables carry a transcription line (batch N transcribed, IDs listed) and a batch not on that line
  is not canon no matter who has built against it. Specific cause, cheap to close: this seat authors
  rulings as documents, and a document is not an export — every batch gets its file at issue, not at
  export.

- **C22.1 · DD 2026-08-02:** one ruling, one ID; the earlier ID governs and the later becomes a
  cross-reference. **T53 ≡ R16 · T54 ≡ R22 · T55 ≡ R19(a) · T56 ≡ R19(c).** The substance is
  identical, so **no lane changes work** — this is keying only, and it matters because a second ID
  makes a closed item look open and invites a lane to build it twice. Fold batch 6's additions into
  the governing lines: T53's "every gate states what it cannot see" → C18; T55's "outranks all room
  polish" → R19's ordering clause; T56's "sequence after T48, hold the 43.9 mattress value" → R19(c).
  **T57 stands** — the only room line in batch 6 with no batch-5 twin; re-key its "same five objects
  as T53" to R16. Strike T53–T56 as rows, keep them as cross-references so the dispatch history
  stays traceable. Substantive addition to R19 while here: the steel/conduit **hue does not wait for
  T48; the value does.** Re-measure both after the black point goes neutral — a blue black point has
  been misreporting every warm-neutral surface in the room, which is plausibly how the built values
  came to be 30–60% lighter in the first place.

- **C23 law · DD 2026-08-02:** where a document and a build disagree on an unbounded parameter, and
  every design-verified frame of that surface contains the build's value while the document's value
  has never been seen, the build is the spec and the document corrects. **Bounds, and they are the
  whole law:** only a named parameter with no measured law and no stated bound attached; never a
  value a law measures (luminance floors, contrast ratios, the fact floor, gold rationing, the
  ladder); never a value that has not been read at review distance. Outside those bounds a drift
  would launder itself by surviving one review. This is C11's converse — a document sentence that
  has never been rendered is not evidence either, and under 1:1 it can otherwise force a change to a
  build five reviews have accepted. Promoted from R27.

- **S44 ruled — violation · DD 2026-08-02:** the machine does not wear the house's brand. The
  wallpaper's `SURE THING.` is drawn in toner **and biro** — the two-ink rule failing in the largest
  element on the screen, since biro is only ever what he chose (S18 ruled the inverse case).
  Wallpaper is the lifted olive-black ground and its toner grain, nothing above the fact floor; if a

  ink decides it before the story question is reached, and the story question still deserves its
  answer: *a man whose own machine wears the house's wallpaper is a man the house already has* is the

  characterisation and becomes ownership — S8 was Design-verified on the finding that this chrome
  reads as *his* machine, personal not institutional, and a wallpaper carrying the operator's logo
  contradicts a Design-verified item on the same surface. The institution-versus-his contrast is the
  single lever the two-register architecture hangs on (T55/R19 ranks a material above all room polish
  for exactly this reason). It is not spent on a wordmark.
