## C46-am — a box sized before a law cannot satisfy it by accident

**Amendment to C46, promoted from TV's own observation.**

C46 ruled that a fixed box carries an unstated assumption about **the face it was sized against.** The
same box carries a second unstated assumption: **about the set of obligations its control had when the
box was drawn.**

**Every correct ruling that adds a required element to a control — a cost, a contract, an instruction,
a state — makes that control's box worse.** Four consecutive rulings did it on one surface.

**This is not evidence the rulings are wrong.** It is the boxes encoding an older contract, and it has
a consequence worth having in advance:

> **When a ruling adds an element to a control, the box's fit is re-derived in the same breath as the
> ruling** — not discovered by a sweep two batches later. The ruling states whether it expects the box
> to still hold, and where it cannot say, it says that.

**And the remedy is usually composition, not span:** a control that has acquired a fourth obligation is
rarely fixed by widening: it is fixed by admitting it now has more than one row's worth of things to
say. Three instances on this surface in one pass — the intervention prompt, `TakeoverSub`, the money
control — all answered by **N independent strings are not one row.**
