## The reasoning these predictions rest on

The exemplar change is a **pure selection change**. `combos.Find(a, b)` reads a row out of a combo
table that was already computed over every pair; the scan itself does not know which pair G5 will
assert on. No RNG is consumed differently, no run is simulated differently, no other gate reads the
exemplar. Campaign A already measured this pair at **+2.87pp ±0.35, 8.1× its own error**.

So this is not really a re-measurement — it is a re-*selection*, and the strong prediction is that
**everything except G5 comes back bit-identical**. That makes it a sharp check rather than a soft
one: if any other figure moves, something unintended changed and the exemplar move is not what did it.
