# Laptop OS & Sportsbook Implementation Plan

_Ratified 2026-07-19 (playtest #16 redirect + grill + design sign-off). The laptop stops
being a railroaded menu and becomes the degenerate's computer: a mimic OS whose sportsbook
app carries a modern card-book betting UI. Design of record: the signed-off mockup
(artifact "Laptop OS & Sportsbook — Design Review", label first-review-draft) — SureThing.
branding, violet accent, two-column cards, mirror-only during sweat, cheap Rewards tab._

## Grill + design rulings (Allen, 2026-07-19 — all of record)

1. **OS depth: app-switcher.** Desktop with wallpaper + icons; apps open FULL-SCREEN; a
   taskbar home button returns. No draggable windows.
2. **Shop: Rewards tab inside the book, deliberately low-polish.** The real vision —
   relics as physical objects in the room (CloverPit-style) — is a future vertical slice.
3. **Book style: modern card book.** Matchup cards + slip drawer; micro-market rows
   designed in NOW as greyed "soon" chips (the micro-markets plan plugs in with zero
   redesign).
4. **During sweat: freely browsable, MIRROR-ONLY.** The TV keeps the show and the E
   cash-out; the laptop's MY BETS mirrors revealed state and never acts.
5. Branding: **SureThing.** / "the number never lies" / brand accent violet #9B5CF6
   (theater pool — reserved-palette safe). Desktop set v1: SureThing + Old Slips live;
   Mail + Bank greyed "(soon)" satire hooks. Clock pinned to the small hours; battery low.

## Laws

- **Reserved palette (design/08)** holds inside the OS: green/red/gold/cyan are money
  signals only. Picked odds buttons and LOCK IT IN are brand-violet, never green/gold.
- **Causal mirror (the one hard law here):** during a sweat the engine has already
  repriced at MoveNext, but the TV defers chrome to scene payoffs. The laptop mirror MUST
  read the TV's REVEALED view — never the engine session directly — or the laptop spoils
  the show. TvSweatScreen exposes a small read-only `RevealedView` (prob, score, clock
  text, market-suspended, per-leg presented states) that it updates exactly where it
  updates its own chrome; MY BETS polls that and nothing else. Team colors from
  TheaterPalette (one authority).
- Engine/economy untouched: all placement still flows through `BetslipModel` +
  `RunDirector.LockRound` / `Run.PlaceTicket`; zero engine RNG in presentation.
- The couch contract is untouched: E-on-the-TV cash-out, sitting/standing law, the
  zero-ticket lock confirm.

## Component map

```
DeskFocus/LaptopScreen (host: zoom, cursor, canvas — slims to a shell host)
  └─ LaptopOs            (desktop: wallpaper, icons, taskbar, toasts, app switching)
      ├─ SportsbookApp   (SureThing: header chrome strip + LOBBY / MY BETS / REWARDS tabs)
      │    ├─ Lobby      (2-col matchup cards: team dots/records/ML buttons + "soon" market
      │    │              row; slip drawer: legs, modifiers, fraction chips, ±$10, LOCK IT IN)
      │    ├─ MyBets     (mirror-only: live ticket strips off TvSweatScreen.RevealedView,
      │    │              sweat banner, resolved legs in money colors, up-next tickets)
      │    └─ Rewards    (cheap reskin of the dealt-hand shop + Manager + sell-backs)
      └─ OldSlipsApp     (flavor: the run's settled tickets, minimal list)
```

Phase behavior: Betting → LOBBY. Sweat → OS browsable, MY BETS live, LOBBY board frozen
("board closed" state). Shop → REWARDS (toast nudge). RunOver → full-screen verdict with
NEW RUN (prototype flow retained). The GO WATCH page dies; the MY BETS banner replaces it.
