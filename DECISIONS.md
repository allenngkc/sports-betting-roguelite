- **2026-07-09 — Debt-as-HP failure model APPROVED (Allen).** Miss a target with no debt → the bookie floats you: bank topped up to the target (working capital), debt = shortfall × (1 + juice rate, default 0.5, sim-tuned). Clearing target + debt at a later settle repays it in cash. Miss while already in debt = run over. No borrowing on the final round. Rationale: converts geometric instant-death into accumulating pressure so runs reach the relic-compounding band; thematically native (the bookie).
